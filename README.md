# 📹 Reproductor de Video Multi-formato en HTML5

Este repositorio contiene un laboratorio en HTML5 que muestra el uso avanzado de la etiqueta `<video>` para reproducir videos de forma nativa en navegadores web.

Implementa buenas prácticas como el soporte de múltiples formatos de origen (`<source>`) para asegurar la máxima compatibilidad entre diferentes navegadores, además del uso de imagen de portada (*poster*), reproducción silenciada (*muted*) y bucle (*loop*).

---

## 🚀 Características

* **Soporte Multi-Formato:** Incluye fuentes en formatos MP4, WebM, OGG y QuickTime (`.mov`) para fallback automático según el navegador del usuario.
* **Imagen de Portada (Poster):** Uso del atributo `poster` para mostrar una vista previa antes de iniciar la reproducción.
* **Control de Reproducción:** Atributos nativos como `controls`, `loop` (repetición continua) y `muted` (reproducción en silencio).
* **Sin Dependencias:** HTML5 estándar sin necesidad de librerías ni reproductores JS externos.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Etiquetas nativas `<video>` y `<source>`.
